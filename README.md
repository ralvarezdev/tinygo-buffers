# tinygo-buffers

TinyGo data type converter functions with reused buffers, for Go projects.

**Note:** This repository is archived and read-only.

## Features

- **`Uint8ToHex`, `Uint16ToHex`, `Uint32ToHex`, `Uint64ToHex`** — Unsigned integers to hexadecimal bytes.
- **`UintToDecimal`, `IntToDecimal`, `UintToDecimalFixed`** — Integers to decimal bytes.
- **`Float64ToDecimal`** — Float to decimal bytes with a given precision.
